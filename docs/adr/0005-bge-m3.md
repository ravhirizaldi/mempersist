# 0005: BGE-M3 initial embedding model

- Status: Accepted

## Context

The corpus mixes Bahasa Indonesia, English, code, product names, errors, and informal language.

## Decision

Use Cloudflare Workers AI `@cf/baai/bge-m3`, validate 1024-dimensional output, keep inputs well below advertised limits, and set `truncate_inputs: false`.

## Consequences

The initial Vectorize index is fixed at 1024 cosine dimensions. Model identity and generation are explicit, and canonical content remains model-independent.

## Alternatives

English-only models were rejected for multilingual quality. External embedding APIs add credentials and egress. Local token/model infrastructure is incompatible with the Cloudflare-native simplicity goal.
